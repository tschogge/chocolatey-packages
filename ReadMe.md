# Chocolatey Packages

[![Chocolatey](https://img.shields.io/badge/Chocolatey-Packages-red.svg)](https://chocolatey.org/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

**Custom Chocolatey packages repository** by [Tschogge](https://github.com/tschogge)

This repository contains Chocolatey packages for various applications that are not available or up-to-date in the [official Chocolatey Community Repository](https://community.chocolatey.org/packages).

## 🚀 Usage

### Install a package
```powershell
choco install PACKAGE_NAME -y
```

### Install directly from source

```powershell
choco install PACKAGE_NAME -y --source="https://github.com/tschogge/chocolatey-packages/raw/main/"
```

---

## 📝 Notes

- **Package names may differ** from their original software names (e.g., `cold-turkey-blocker` vs `cold-turkey-manager`)
